Git

  • git init — инициализировать локальный Git-репозиторий в текущей папке.
  • git clone [url] — клонировать (скачать) удаленный репозиторий на компьютер.
  • git status — проверить состояние файлов (какие изменены, какие подготовлены к коммиту).
  • git add [файл] — добавить измененный файл в индекс (подготовить к сохранению). Команда git add . добавляет все файлы.
  • git commit -m "сообщение" — сохранить изменения в локальный репозиторий с описанием того, что было сделано.
  • git push — отправить сделанные локальные коммиты в удаленный репозиторий (например, на GitHub).
